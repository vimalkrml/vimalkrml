## Featured Project

### PayLater: Fintech Operations Platform
A role-based internal dashboard for a Singapore-based loan management company. It replaces a fragmented multi-tool workflow with a single operations hub, where admins, supervisors, reviewers, and developers each work within defined access boundaries.

- **Modules:** Enquiry Tracking · Applications · Customer Records · Loan Closure · Collections · Reports · Staff Access Control · Notifications · Templates · Login Activity · API Integrations · Live Staff Presence
- **Highlights:** collapsible role-aware sidebar, real-time Singapore time header, module switching without page reloads
- **Stack:** React · Node.js · Express · MySQL · AWS S3 · GitHub Actions
